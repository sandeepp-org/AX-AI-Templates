# Back-end

The API workspace: `app/` (the Express application) and `packages/` (reusable `@util/*` packages).

```bash
pnpm install
pnpm dev      # http://localhost:3001, GET /api/v1/health
```

The folder structure, the dependency rules between layers, how to add a feature and every command are described
in the [repository README](../README.md#back-end).
