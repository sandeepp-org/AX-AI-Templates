# Front-end

The web workspace: `app/` (the Vite + React application) and `packages/` (reusable `@canopy/*` packages).

```bash
pnpm install
pnpm dev      # http://localhost:3000, renders Hello World and the API status
```

The API must be running for the page to show **API status: ok** (see `../back-end`).

The folder structure, the package graph, how to add a feature and every command are described in the
[repository README](../README.md#front-end).
